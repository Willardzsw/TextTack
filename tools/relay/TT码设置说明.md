# 用 TT码在 TextTack 里翻译

不用自己申请 API Key，填我给你的 TT码就能用。需要 TextTack 1.18.0 或更新的版本。

## 设置步骤

1. 打开 TextTack，进入 **设置 › 翻译服务**，找到 **云翻译**，点 **设置**。
2. 在 **TT码** 一栏粘贴我发给你的码（`tt-` 开头）。
3. **模型** 按需选择：
   - **GPT-6 Luna**：默认选项。
   - **DeepSeek Flash**：速度更快。
4. 关闭设置窗口，在翻译服务里选中 **云翻译**。

地址、提示词和参数都已经设好，不用改。点 **查看额度** 可以看今天用了多少、还剩多少。

## 可能看到的提示

| 提示 | 意思 |
|---|---|
| TT码不对 | 检查有没有多复制了空格，或者找我换个新码 |
| 今天的额度已经用完 | 每人每天有上限，曼谷时间零点后恢复 |
| 请求太频繁 | 稍等一分钟再试 |
| 这个模型暂时不可用 | 在云翻译设置里换另一个模型 |
| 服务器的账户出了问题 | 不是你的问题，告诉我一声 |

## 请注意

- TT码只给你自己用，不要转给别人。
- 你要翻译的文字会经过我的服务器，再转给 OpenAI 或 DeepSeek。服务器不保存翻译内容，只记录每天用了多少。
- 不要用它翻译密码、身份证号这类敏感信息。

## 旧版本 TextTack

如果还没升级到 1.18.0，也可以用 **OpenAI** 服务。在它的设置里填：

- API 地址：`https://tt.allplusthailand.top`
- API Key：你的 TT码
- 模型名称：`gpt-6-luna` 或 `deepseek-flash`

然后在模型设置里勾选 **关闭思考**。
